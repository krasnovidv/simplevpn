# RKNPNH — Редизайн «Жидкий хром» · Handoff для Claude Code

## Что это
Полный редизайн Android-приложения RKNPNH (VPN, **один сервер** — Амстердам). Направление — Y2K «жидкий хром»: перламутровые меш-градиенты, живая металлическая сфера-кнопка, дерзкие подписи.

**Файлы в папке — это дизайн-референсы на HTML/React**, а не продакшен-код. Задача: пересобрать экраны в существующем Android-проекте (предпочтительно Jetpack Compose + Material 3) по его паттернам. HTML — источник истины по виду, поведению, таймингам и текстам.

Как смотреть: `python3 -m http.server` в этой папке → открыть `RKNPNH Chrome.html`. Всё кликабельно (сфера, кнопки, вкладки, свитчи, тема).

Fidelity: **high-fi**. Цвета, шрифты, радиусы, тексты — финальные.

## Файлы
- `RKNPNH Chrome.html` — холст: 7 экранов × тёмная/светлая.
- `y2k/core.jsx` — токены (`DIRS.chrome`), фоны (`Backdrop`), иконки, стили карточек/кнопок.
- `y2k/heroes.jsx` → `ChromeHero` — хромовая сфера (главная анимация). Остальные hero (`AcidHero`, `JellyHero`) — отброшенные направления, **игнорировать**.
- `y2k/screens.jsx` — все экраны, навигация, машина состояний (`App`).
- `design-canvas.jsx` — только оболочка холста, не переносить.

## Машина состояний подключения
```
idle ──tap──▶ connecting ──(~2.6 s / реально: туннель поднят)──▶ connected
connected ──tap──▶ disconnecting ──(~1.3 s)──▶ idle
любое ──нет сети──▶ error (экран «Нет сети»)
```
Первый запуск: `onboarding` → «Спрятаться» → системный диалог `VpnService.prepare()` → ОК → `main` + сразу `connecting`. Отмена — остаёмся на онбординге.

## Фон (`Backdrop`, chrome)
Три размытых круга 340px (`blur(70px)`): тёмная `#5B3BFF / #00D1FF / #FF4FD8` (opacity .45), светлая `#B9A8FF / #9BEAFF / #FFB8E6` (.7). Позиции (-80,80), (180,300), (40,560). Бесконечно дрейфуют (14/18/22 s ease-in-out), при `connecting` в 3 раза быстрее. Интенсивность: idle ×0.6, connected ×1, error ×0.35 (переход 1 s). Сверху — точечный шум 4px (`radial-gradient 1px`, 5% opacity).
Compose: `Canvas` + `RenderEffect.createBlurEffect` / `Modifier.blur`, анимировать через `rememberInfiniteTransition`.

## Главная анимация — хромовая сфера (`ChromeHero`)
Метаболы: центральный шар + 4 спутника, слитые «gooey»-эффектом (blur `size*0.035` → alpha-threshold матрицей `0 0 0 24 -10`), залитые вертикальным хром-градиентом из 5 стопов + голографический поворотный слой (mix-blend color) + **динамический мягкий блик**: радиальный градиент белый→прозрачный (без жёстких краёв), blend screen. Блик ездит по сфере за медленным «виртуальным источником света» (угол ≈ −2.2 + 0.9·sin(0.35t) + вращение), вытянут по касательной к поверхности, дышит по размеру, на волнах ряби вспыхивает (+25% яркости и ширины). Напротив — слабый рефлекс-отблеск (opacity ~.18). В error блик тусклый (.25).

Параметры по состоянию (плавно интерполируются, lerp ~0.05–0.08 за кадр):
| mood | spread спутников | скорость вращения | радиус центра | holo | палитра |
|---|---|---|---|---|---|
| idle | .30 | .5 | .27 | .08 | серебро `#FFF/#D6DAE6/#474B61/#9AA0B8/#F4F5FB` |
| connecting | .42 | 3.2 | .24 | .35 | + пунктирная орбита-эллипс вращается 120°/s |
| connected | .02 (всё сливается в сферу) | .6 | .33 | .55 | радуга `#FFF/#B8F4FF/#5E4BFF/#FF9EE6/#FFF6C9` + пульсирующее свечение accent |
| disconnecting | .38 | 1.6 | .26 | .15 | холодное серебро |
| error | .20, спутники «стекают» вниз | .15 | .25 | — | тусклый `#F4ECEC…` |
**Рябь / волны (живость).** Периодически по сфере расходятся волны: idle каждые ~3.8 s, connecting ~1.1 s, connected ~2.6 s, disconnecting ~1.6 s (±30% рандом), error — нет. Плюс волна на каждый тап (сильнее ×1.4, из центра). Каждая волна живёт 1.8 s с огибающей `exp(-age·2.6)` и делает три вещи:
1. **Кромка дрожит** — радиус центрального шара модулируется `r·(1 + 0.075·env·sin(k·θ − age·14))`, k = 5–8 лепестков — бегущая волна по контуру.
2. **Кольца** — 3 концентрических кольца из случайной точки около центра расширяются (скорость ~0.95·S/2 в секунду, шаг .13), белая линия 3.2→1.6 px + тёмная «рефракционная» линия внутри, всё гаснет к 1.8 s; обрезаны формой сферы.
3. **Рябь заливки** — хром-градиент и голо-слой проходят через displacement-шум (fractal noise, baseFrequency ≈ 0.012×0.03, медленно плывёт); сила смещения 3 px в покое → до ~27 px на пике волны. Голо-слой на волне ярче (+0.25).
На AGSL это естественно делается в том же шейдере: `uv += normal * sin(dist*freq − time*speed) * env` + noise-displacement.

Размер: 270 на главном, 300 онбординг, 190 ошибка, 140 в виджете.
Нажатие: scale .94 на spring. Всё — тап-таргет (300px по высоте).

Реализация на Android: **AGSL `RuntimeShader`** (API 33+) — метаболы как SDF-поле + градиент — лучший вариант; фолбэк для <33: `Canvas` circles → `RenderEffect` blur + `ColorMatrixColorFilter` threshold, либо Lottie/видео-лупы по 4 состояниям. Держать 60 fps, уважать «Анимации на максимум» = off → статичные кадры.

## Экраны
Статус-бар и gesture-pill — системные (edge-to-edge). Нижняя навигация (M3 NavigationBar, 100 высоты с инсетом): **Главная / Приложения / Настройки**; активный индикатор — пилюля 64×32 с хром-градиентом, иконка onAccent; переход ширины 32→64 на spring.

### 1. Онбординг
Wordmark вверху. Сфера 300 (idle; при открытом диалоге — connecting). Заголовок **«ПРИВЕТ, / НЕВИДИМКА»**. Текст: «Один сервер, одна кнопка, ноль вопросов. Сейчас Android спросит разрешение — не пугайся, он всех спрашивает.» Внизу primary **«Спрятаться ›»** + «Без логов · без регистрации · без одобрения». Системный диалог VPN — нативный (в макете — имитация).

### 2. Главный
Top: wordmark `RKNPNH` (Unbounded 20, градиентный текст) + чип статуса (pill, blur, точка-индикатор со свечением; пульс при connecting/disconnecting).
| состояние | чип | заголовок | подпись |
|---|---|---|---|
| idle | засвечен (bad) | ТЕБЯ / ВИДНО | РКН уже подглядывает. Жми на штуку — исчезнешь. |
| connecting | прячемся | ПРЯЧЕМ / ТЕБЯ… | Заметаем следы, путаем провода… |
| connected | невидимка (good) | ТЕБЯ / НЕТ | Для всех ты в Амстердаме. Для мамы — дома. |
| disconnecting | выходим | СНИМАЕМ / МАСКУ… | Возвращаем тебя в поле зрения. Сам захотел. |
Сфера по центру. Карточка сервера: флаг-кружок NL, «Нидерланды», «Амстердам · единственный и любимый», справа 4 полоски сигнала (горят: idle 1 серая, connecting/disconnecting 2, connected 4 цвета good). **Выбора сервера нет.** Разделитель, нижняя строка:
- connected: таймер `HH:MM:SS` + «IP 185.93.0.42»
- idle: «Твой IP 93.184.27.11» + «его видят все» (bad)
- connecting: «Ищем самый тёмный угол…», disconnecting: «Закрываем туннель…»

### 3. Приложения (split tunneling)
Заголовок **«КОМУ / БЕЗ МАСКИ»** (36). «Эти приложения пойдут напрямую — **N из M**. Остальные спрячем.» Сегмент-контрол 3 режима: *Всё через VPN / Кроме этих / Только эти* (активный — градиент). Поиск (pill 50). Список установленных приложений в карточке: иконка 42 (radius 14), имя, шуточная подпись, свитч. В режиме «Всё через VPN» список .4 opacity и неактивен. Подписи-примеры: Госуслуги — «им и так всё известно», Сбер — «банки не любят Амстердам», Telegram — «а вот тут лучше с нами», YouTube — «без нас — слайд-шоу», Яндекс Карты — «чтобы такси нашло тебя», Instagram — «сам знаешь почему». Для прочих приложений — без подписи или пул общих шуток.

### 4. Настройки
Заголовок **«НАСТРОЙКИ»** (30). Группы (лейбл 12/800 caps, sub):
- **Защита:** Рубильник (kill switch) — «Упал VPN — режем интернет, чтобы ничего не утекло»; Автоподключение — «В чужом Wi-Fi включаемся сами»; Режим «Я не VPN» — «Притворяемся скучным HTTPS-трафиком».
- **Соединение:** Протокол → VLESS Reality; DNS → Свой, без слежки. (**Строки «Сервер» нет.**)
- **Внешний вид:** сегмент Светлая / Тёмная (плюс в проде — «Как в системе»); «Анимации на максимум» — «Батарейке будет грустно. Нам — весело»; «Статус в шторке» — «Таймер и трафик в уведомлении».
Футер: «RKNPNH 2.0 · сделано без одобрения».

### 5. Рабочий стол: виджеты + уведомление
- **Ongoing-уведомление** (foreground service): «RKNPNH · 01:12:10», «Ты невидимка», «Амстердам · спрятали 342 МБ», одно действие «Отключить». В idle — «Ты снова на виду» / «Нажми, чтобы исчезнуть» / «Подключить».
- **Виджет 4×2** (Glance): мини-сфера 140 + «ТЕБЯ НЕТ» + «Амстердам · таймер» + пилюля Вкл/Выкл. Тап = toggle.
- **Виджет 2×2 кнопка:** круг 96 с иконкой power (градиент когда вкл, пунктир sub когда выкл) + «спрятан / на виду».
- **Виджет 2×2 статистика:** «СЕГОДНЯ / 1,2 ГБ / спрятали от глаз».
Карточки виджетов — тот же card-стиль с градиентной обводкой. В Glance анимация сферы — статичные кадры по состояниям (или анимированный `AnimatedImageDrawable`).

### 6. Нет сети
Чип «нет сети». Сфера error 190. Заголовок **«ИНТЕРНЕТ / УШЁЛ / ЗА ХЛЕБОМ»** (36). «Проверь Wi-Fi или мобильные данные. Мы подождём — нам не привыкать.» Primary «↻ Попробовать снова» → main + connecting. Ghost «Настройки Wi-Fi» → `Settings.Panel.ACTION_INTERNET_CONNECTIVITY`. Snackbar (въезжает снизу, spring, delay 300ms): «Рубильник сработал: интернет выключен, ничего не утекло» + «ОК» — показывать только если kill switch реально сработал.

## Иконки
Stroke 2, round caps, 24 grid: home-щит, apps (4 квадрата), gear, chevron, search, retry, power, bolt. Можно заменить на Material Symbols Rounded weight 500 — близко по характеру.

## Приёмка
- Все 4 состояния подключения + error проигрываются плавно, без рывков; сфера 60 fps.
- Тёмная и светлая тема на всех экранах; градиентный текст на светлой читается.
- Тексты — точно как в макете (тон — ключевая часть бренда).
- Нигде нет выбора сервера.
- «Анимации на максимум» = off и системный reduce-motion → статичные состояния.
- Тап-таргеты ≥ 48dp.
